# مساعد السيرة الذاتية (Resume Assistant)

مشروع تفاعلي لمساعد ذكي يقوم بقرائة نصوص السيرة الذاتية، استخراج المهارات التقنية، وتقديم نصائح واقتراحات فورية لتطوير المحتوى وتحسين جودته.

---

## 💡 فكرة المشروع
يهدف المشروع إلى تسهيل مراجعة وتدقيق السير الذاتية باستخدام التقنيات البرمجية، حيث يتلقى النص المكتوب من المستخدم ويحلله فورياً لإظهار المهارات المكتشفة وتوفير ملاحظات إيجابية واقتراحات تحسين في واجهة رسمية بسيطة وسهلة الاستخدام.

---

## 🤖 دور الوكيل (Agent) والـ Skill

* **الوكيل (Agent - `agent.toml`):**
  يمثل الهوية والوظيفة الأساسية للبرنامج، حيث يحدد اسم المساعد (`ResumeReviewer`) ودوره كمستشار لمراجعة السير الذاتية، ويقوم بربط واستدعاء المهارات البرمجية المخصصة.

* **المهارة (Skill - `skill.py`):**
  تمثل المحرك والطقس التنفيذي للذكاء؛ حيث تحتوي على منطق البرمجة المخصص لفحص النص، استخراج المهارات البرمجية (مثل Python وJavaScript وغيرها)، وصياغة الاقتراحات والملاحظات بناءً على المحتوى المدخل.
