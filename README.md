# مساعد السيرة الذاتية (Resume Assistant)

مشروع بسيط لمساعد برمدي ذكي يقوم بقرائة نصوص السيرة الذاتية، استخراج المهارات التقنية، وتقديم نصائح تحسين خفيفة.

## هيكلة المشروع
- `agent.toml`: ملف إعدادات وتخصيص دور الوكيل.
- `skill.py`: يحتوي على المهارة (Skill) الخاصة بتحليل النص واستخراج المهارات.
- `app.py`: ملف التشغيل والتجربة الرئيسي.

## طريقة التشغيل
1. التأكد من تثبيت Python 3.
2. تشغيل الأمر التالي في الـ Terminal:
   ```bash
   python3 app.py
